# Megha Verma — Portfolio Website

A responsive, single-page portfolio built with HTML, CSS, and JavaScript.

## Files
- `index.html` — page content and structure
- `style.css` — responsive styling and visual design
- `script.js` — mobile navigation and project detail dialogs
- `megha-portrait.png` — homepage background image

## Projects
- Servly: [GitHub repository](https://github.com/MeghaVerma2025/Servly)
- Versefy: prototype / work in progress
- Portfolio: this website

The Servly repository link opens the source-code repository. It does not by itself make the Servly app live or connected to a backend.

## Run locally
Open `index.html` in a browser. No build step is required.

## Publish with GitHub Pages
The site is configured for GitHub Pages from the `main` branch and `/ (root)` folder.

## Homepage design note
- The portrait remains the full-page background image.
- The decorative floating workspace panel has been removed from the hero section.
- Section headings use labels without numeric prefixes.
