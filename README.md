# Megha Verma — Portfolio Website

A responsive, single-page personal portfolio built with HTML, CSS, and JavaScript.

## Files
- `index.html` — page content and structure
- `style.css` — responsive styling and visual design
- `script.js` — mobile navigation and interactive project detail dialogs
- `megha-portrait.png` — portrait image used in the hero section

## Run locally
Open `index.html` in a browser. No build step is required.

## Before sharing with employers
1. Verify your contact details and social links.
2. Update the project statuses so they accurately reflect what is working today.
3. Add repository links and live demos only after the relevant code is uploaded and tested.
4. Do not describe planned features as completed features.
5. Consider adding screenshots of the real running projects once available.

## Publish with GitHub Pages
1. Create a GitHub repository named `portfolio-website`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Choose deployment from the `main` branch and the `/ (root)` folder, then save.
5. Wait for GitHub Pages to publish the site and open the provided URL.

## Customization
Search in `index.html` for your name, contact details, project descriptions, and links. Edit the color variables near the top of `style.css` to adjust the theme.
